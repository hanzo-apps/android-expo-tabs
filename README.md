# android-expo-tabs

Expo Router tab navigation starter — typed routes, themed components, light/dark.

**Lane:** Expo / React Native · **Live demo:** https://android-expo-tabs.hanzo.app

## Run it on Android

```sh
npm install && npx expo run:android
```

## Provenance

Forked from [expo/expo](https://github.com/expo/expo) — `templates/expo-template-tabs`, licensed **MIT**.
The upstream `LICENSE` is kept verbatim in this repo; the copyright stays with
its authors. Changes made here are limited to what a standalone fork needs
(see the initial commit).

## Preview

`npx expo export -p web` produces the static bundle served at
https://android-expo-tabs.hanzo.app — the same app the Android build runs, rendered by
react-native-web. It is a real running app, not a screenshot.
